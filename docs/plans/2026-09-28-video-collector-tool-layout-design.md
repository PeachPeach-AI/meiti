# 视频采集工具台设计

## 目标

将视频采集从信息展示页改为桌面工具工作台：左侧查看已连接页面，右侧管理采集，界面不出现不参与操作的标题、说明或概览。

## 布局

窗口内容仅有两栏。左栏是连接页面的静态占位浏览器，保留地址和连接状态以建立“软件正在操作外部页面”的心智。右栏上部是关注账号与定时任务，账号区下方放置立即采集；下部为采集结果表。两栏之间的细分隔条可拖拽，适应用户对页面预览与数据操作的不同偏好。

## 交互边界

拖拽只改变当前会话的栏宽。采集、保存任务和导出仍为原型中的反馈动作；不连接第三方平台、不存储真实任务，也不执行真实采集。

## 验收

- 页面不再显示“视频采集”大标题、副标题或解释说明。
- 左、右栏清晰且由可拖拽分隔条隔开。
- 立即采集位于账号与定时设置之后、结果表之前。
- 结果字段保持视频名称、账号、视频地址、发布时间、浏览、点赞、评论、收藏。

# 本地热更新设计

## 目标

本地开发只维护一个便携版 EXE。页面、样式和样例数据从固定的本地目录加载，避免每次界面修改都重新分发程序。

## 方案

EXE 启动时优先读取 `E:\\BaiduSyncdisk\\lab\\60smartStore\\hot-update`。该目录包含 HTML 与 `assets` 子目录。开发时更新该目录中的资源，在软件窗口按 `Ctrl + R` 或重启即可重载；如果目录或主页不存在，则安全回退到 EXE 自带的静态资源。

## 边界

这是仅面向当前电脑的开发热更新，不是网络更新服务。EXE 主进程和 Electron 版本变化时才需要重新构建单一同名程序。

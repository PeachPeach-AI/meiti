# 选题库设计（AI 内容运营中心 · 第 5 个 Tab）

日期：2026-10-04 · 状态：已确认（用户口头批准）

## 定位

选题库 = 未来内容生产的统一入口。所有渠道的选题先进池，再推送到「今日任务」进入生产流。

```
智慧录音分析 ─┐
视频评论 ─────┤→ 选题库（统一池）→ 推送今日任务 → 生产 → 我的内容
用户私信 ─────┤        ↑
手动录入 ─────┘   （业务下发/账号适配/裂变等原有来源也进池）
```

## 数据模型（扩展 D.topics，不新增集合）

- 新增来源枚举：`source: 'comment'`（视频评论）、`'dm'`（用户私信）；沿用 recording / manual / business / account / fission。
- 手动录入与「运营下发」共用 `source:'manual'`，靠 `sourceLabel`（手动录入 / 运营下发）区分展示。
- 新增字段：`bizCategory`（业务分类，一级分组）、`note`（备注/原始问题摘录）、`createdAt`。
- 业务分类（广电口径）：家庭宽带 / 家庭组网 / 5G号段 / 电视业务 / 套餐合约 / 融合套餐 / 校园业务 / 携号转网 / 其他。

## 界面（v2 风格复用）

- Tab 顺序：今日任务 / 省内优秀库 / 爆款仿制 / 我的内容 / **选题库**。
- 左侧：业务分类分组列表（v2list），带数量徽标，点击筛选；底部「+ 录入选题」。
- 右侧：来源筛选条（全部/录音分析/视频评论/用户私信/手动录入）+ 选题表格（标题、来源标签、业务分类、创建时间、状态、操作）。
- 操作：
  - **推送今日任务**：`V2.topic = id; V2.tab = 'today'`，一键进入当日生产；
  - 删除：从 D.topics 移除；
  - 手动录入：openSheet 弹窗，极简三字段（标题、业务分类下拉、备注），来源自动记「手动录入」。

## 口径

- P0 原型不变：演示级、内存态（V2 闭包不入 localStorage），样例数据在 data.js。
- 旧页面（D.topics 其他消费方）零改动；scriptgen 兼容：新样例仍带 hook/say，推送今日任务后可正常生成口播稿。

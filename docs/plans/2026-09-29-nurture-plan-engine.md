# 养号面板规则化计划（引擎化收尾的最后一项）

> 上级文档：`2026-09-29-solution-v2-design.md`；模式：TDD。
> 背景：养号页是「配置 + 模拟运行态」UI，配置数字（stage/day/target）本身是样例配置可保留；
> 真正缺的是**实时推导层**——把账号诊断状态与录音洞察接进养号页。

**Goal:** `SSCore.nurturePlan(accounts, recAnalysis, config)` 实时推导养号「今日要点」：

1. 参与中的**断更账号** → 要点「先补发布，再养号」（养号浏览不能替代发布）；
2. 参与中的**未授权账号** → 要点「养号行为无法归集到诊断，先授权或手动导入」；
3. **关键词缺口**：录音 TOP5 高频问题逐一比对养号关键词，未命中者列为缺口并给出覆盖率
   ——打通「录音洞察 → 养号关键词」，是本项的核心价值（样例数据预期：TOP5 覆盖 4/5=80%，
   「路由器怎么选」为缺口）；
4. 全部要点相关性措辞（只描述命中与否，不推断养号效果），带口径说明。

**接线：** 养号页头部下方新增「今日要点 · 实时推导」区块（要点行 + 缺口说明 + 口径）；
配置数字与模拟运行态保持原样（演示性质，非遗漏）。

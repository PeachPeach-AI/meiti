# AI智慧门店内容开工台：首页原型设计

## 目标

为一线营业员提供一个打开即能开始营销内容生产的桌面端首页原型。首页的第一优先级是获取可拍的视频选题与口播稿；账号表现仅作为辅助信息。

## 用户与场景

营业员在开始一天工作或有空档时打开软件，希望无需学习复杂后台，即可快速确定今天拍什么、怎么开场、下一步做什么。

## 信息架构

应用采用固定左侧导航，预留六个入口：主页、账号运营中心、AI内容运营中心、矩阵运营中心、录音洞察中心、经营驾驶舱。

本轮实现主页。页面包含：

1. 顶部问候与当日行动提示。
2. 核心「今日推荐」卡片：选题、受众、推荐理由、3 秒钩子、预计时长，以及生成口播稿的主操作。
3. 快捷入口：从录音问题找选题、查看素材、继续草稿。
4. 待拍内容和可复用素材两列清单。
5. 轻量账号表现摘要，避免数据成为首页主角。

## 视觉与交互方向

采用“温暖的内容开工台”而不是企业管理后台：深石墨侧栏建立工具感，暖白内容区域提高可读性，暖橙色承载关键行动，少量青绿色传达良好状态。信息卡使用大留白和明确层级。

所有数据均为演示数据。导航、选题切换、生成口播稿和快捷入口应提供即时的前端反馈，但不调用网络、不存储数据。

## 验收标准

- 在桌面宽度下，用户能一眼找到今日选题和「生成口播稿」。
- 左侧六个业务板块均可辨识；当前仅主页有完整内容。
- 点击关键操作能看到明确反馈，演示流程不会显得是静态海报。
- 页面不出现传统后台式的大表格、密集筛选项或管理口径为主的布局。

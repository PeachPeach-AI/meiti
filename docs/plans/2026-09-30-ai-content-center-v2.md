# AI 内容运营中心建设方案 v2 —— 每日任务流水线 + 省内优秀库（2026-09-30）

> 状态：方案已评审通过（2026-09-30），本文档为建设蓝本；P0 原型开发另行立项。
> 原则：v2 原型走左侧主菜单独立入口，与现有 AI 内容运营中心 4 页签并行，互不改动，最终由业务评估取舍。

## 一、背景与核心矛盾

中国广电营业厅员工每天被要求发 1 条短视频做营销获客与宣传，但普遍没有内容输出能力、不会剪辑。现有 AI 内容运营中心按功能切分页签（内容推荐 / 口播素材 / 图文混剪 / 爆款仿制），需要员工自己串流程、做选择、甚至自己剪——上手难度高，与员工能力不匹配。

**建设目标**：员工打开就知道今天拍什么、怎么拍、怎么成片、怎么发；全程只做「拍」和「确认」，零文案、零剪辑、少选择。同时把全国（先省内）海量营业厅持续产出的内容沉淀为可复用资产，好内容一键裂变。

## 二、总原则

1. **每日一条**：系统每天自动定 1 条主推选题（业务日历 + 账号人设 + 内容库表现数据），默认不给选择，不满意才换。
2. **零输入**：口播稿、封面图、发布文案、标签全部系统生成，员工不写文案不打字。
3. **一步一个动作**：流程每步只有 1 个主按钮，高级能力（换选题/换风格/换出口）收进「更多」。
4. **新旧并行**：v2 在左侧主菜单（.rail 图标栏）新增独立入口，全新命名空间（`data-od-id: v2-*`、独立 state 前缀），旧 4 页签零改动。
5. **口播素材是内容枢纽**：稿子 ready 后提供两个并列出口——提词器拍摄（出镜口播）与 AI 数字人生成。
6. **内容库是资产层**：所有生成/发布内容自动结构化入库；本期只做「省内优秀库 + 我的内容」两层，一键裂变。
7. **已裁决事项**：独立「图文混剪」功能页不做；图文混剪成片路径删除。

## 三、内容形态规划

| 形态 | 说明 | 员工动作 | 排期 |
|---|---|---|---|
| 出镜口播 | 提词器拍摄 → 模板化自动成片（自动剪/字幕/配乐） | 照提词器拍 | 本期主线 |
| AI 数字人口播 | 选人物形象+音色+BGM → 稿子直接生成数字人视频 | 点确认 | 本期主线 |
| 抖音图文图集 | 选题自动生成 3~6 张图文卡片（标题+要点+门店信息+配图模板），适合攻略/对比类选题 | 点发布 | P2（实现便宜，与现有 canvas 封面技术同源） |
| 门店实拍+智能字幕卡 | 碎片实拍自动选段+字幕卡+AI 配音 | 随手拍 | 远期规划 |
| 客户问答内容 | 常问问题自动生成一问一答内容 | 点确认 | 远期规划 |

## 四、主线：每日任务流水线（今日任务页，v2 默认首页）

### 步骤总览

```
① 选 → ② 装（口播素材枢纽） → ③ 成（双出口之一） → ④ 发
```

### ① 选（每日定题）

- 系统按「营业厅业务日历 + 账号人设 + 省内库历史表现」自动定 1 条选题，附推荐理由与合规校验。
- 不满意 → 「换一条」（仍由系统给，不是自由浏览）；也可从省内优秀库挑一条直接裂变。

### ② 装（口播素材枢纽）

自动生成全套物料（复用现有 scriptgen / canvas 封面能力，改为自动预生成）：
- 3 秒钩子、完整口播稿（分条+时长+字数）、封面图（900×1200）、发布文案、标签、拍摄建议（场景/镜头/字幕重点/动作）。

稿子 ready 后给出**两个并列出口**（员工上次的选择记为默认）：

### ③ 成（双出口）

**出口 1 · 提词器拍摄（出镜口播）**
- 提词器（滚稿、语速、字号）+ 拍摄指导分镜
- 员工拍摄素材 → 上传/回传 → 模板化自动成片：按分镜自动剪、加字幕、配 BGM
- 员工零剪辑操作

**出口 2 · AI 数字人生成**
- 选人物形象（预设若干：亲和女声/专业女声/沉稳男声对应的数字人形象卡片）
- 选人物音频（音色）+ 背景音乐（轻快/温暖/资讯感）
- 一键生成数字人口播视频 → 生成队列 → 完成后进「我的内容」

### ④ 发

- 合规校验前置（沿用现有 matBar 机制）
- 一键复制发布文案 / 标签、下载封面
- 点「已使用」记录 → **自动入内容库**

## 五、内容库与一键裂变（本期范围：省内）

### 入库

每条生成/发布的内容自动以结构化 JSON 入库，零人工整理：

```json
{
  "id": "c-20260930-001",
  "origin": "daily | viral | fission",
  "structure": { "hookType": "反常识", "segments": [{"role":"痛点","sec":8}, ...] },
  "slots": { "region": "南京", "hall": "玄武营业厅", "biz": ["千兆宽带","全家WiFi"], "persona": "王姐" },
  "assets": { "script": "...", "cover": "...", "publish": "...", "tags": [...] },
  "metrics": { "views": 0, "likes": 0, "used": true },
  "level": "mine | province"
}
```

### 两级库（本期）

- **省内优秀库**：省运营精选标杆内容（带数据表现），全省可见。冷启动：省运营把早期表现好的内容手动「收录进优秀库」。
- **我的内容**：本厅已发内容自动沉淀。
- **全国库**：远期扩展，schema 预留 `level` 字段即可，机制相同。

### 一键裂变

库中任选一条 → 点「裂变到本厅」→ 系统识别内容中的**槽位**（地域/门店名/业务点/资费/人物人设）→ 替换为本地变量 + rewrite 润色 → 产出新稿 → 走双出口成片。与爆款仿制同管线（结构保留 + 槽位替换 + 重写），员工零创作。

## 六、爆款仿制（并列内容来源）

### 列表页

爆款卡片：视频封面（截图）+ **爆款原因**一句话（数据表现+结构亮点，如「7 天 12 万赞 · 三段反转+本地化钩子」）+ 地址入口。

### 详情页（左右分栏）

- 左：WebView 播放原视频（复用采集页/养号页 `.browse` 模式）
- 右上：**视频结构分析**（钩子类型/分段结构/每段时长/节奏/字幕关键词）
- 右中：**原台词文案**（ASR 转写+时间轴）
- 右下：**仿写台词文案**（按本店业务裂变重写，可「换一版」）

### 成片出口

仿写稿 ready → 与口播素材相同的双出口（提词器拍摄 / AI 数字人生成）→ 成片 → 我的内容 → 自动入库（origin=viral）。

### 视频分析技术管线（无需员工提供原文件）

1. **入口**：员工粘贴抖音分享链接；Electron 内嵌 WebView 打开视频页解析播放地址与页面数据（采集通道同款先例）；兜底=保存视频后本地上传。
2. **分析**：临时下载 → 双路：**ASR 语音转写**（台词全文+时间轴）+ **ffmpeg 抽帧**（每 2~3 秒一帧）→ **多模态大模型**（GLM-4V/Qwen-VL 级）读帧+转写 → 结构化拆解。
3. **映射**：拆解结果映射到现有 5 段式结构体系 → 复用 rewrite 裂变重写。
4. **合规红线**：原视频仅用于结构分析，不搬运任何画面/音频素材；临时文件分析完即删。

## 七、信息架构

左侧主菜单新增独立入口「AI 内容工厂（新版）」，v2 内页签：

```
今日任务（首页） / 省内优秀库 / 爆款仿制 / 我的内容 / 设置
```

## 八、分期路线与验收

| 期 | 内容 | 验收标准 |
|---|---|---|
| **P0 原型期** | 独立入口 + 今日任务流水线（含素材枢纽双出口）+ 省内库列表/裂变交互原型（模拟数据）+ 爆款列表/详情原型（模拟分析结果） | 员工视角全流程 10 分钟走通；旧页面零改动；可点通演示 |
| **P1 分析与裂变管线** | 链接解析 + ASR/抽帧/多模态真实分析；槽位识别与裂变重写真实化 | 真实抖音链接 3 分钟内出结构拆解+双台词；裂变稿地域/业务替换准确 |
| **P2 成片引擎 + 图文图集** | 出镜素材模板化自动成片；数字人生成（形象/音色/BGM）；抖音图文图集生成 | 各形态出合格内容，员工零剪辑操作 |
| **P3 发布闭环与库运营** | 发布记录、数据回流、省运营收录台、库内数据排序与裂变推荐 | 发布→数据回流→裂变推荐闭环 |

**评估点**：P0 完成后，业务对比新旧两方案，决定谁转正。

- 独立图文混剪功能页

## 十、风险与依赖

| 风险/依赖 | 说明 | 对策 |
|---|---|---|
| 抖音反爬 | 链接解析可能被风控 | WebView 真人浏览兜底 + 本地上传兜底 |
| 多模态分析成本 | 抽帧+大模型调用有费用 | 只在「爆款仿制」显式触发；帧采样降频 |
| 数字人/配音供应商 | 形象与音色需外部能力 | P2 立项选型；P0 用静态形象卡模拟 |
| 内容合规 | 医疗/资费类表述风险 | 沿用合规校验前置，模板内置合规话术 |
| 员工采纳 | 新流程学习成本 | P0 原型先在 1~2 个营业厅试点 |

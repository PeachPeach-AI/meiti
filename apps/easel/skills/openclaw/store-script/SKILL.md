# 门店口播生成

> 面向广电营业厅一线员工：输入业务方向与素材，输出「拿起来就能拍」的口播方案。

## 输入
- 业务方向：宽带 / 5G / 号卡 / 电视 / 融合套餐 / 活动（至少其一）
- 账号画像：定位、受众、语气（可选）
- 参考素材：录音高频问题、评论原文、对标脚本（可选）
- 时长：30 / 45 / 60 / 90 秒（默认 60）

## 输出（结构化）
1. 选题标题
2. 前 3 秒钩子
3. 完整口播稿（口语化，含自然停顿/重音标记）
4. 拍摄建议（场景 / 镜头 / 字幕重点）
5. 封面文案（3 版）
6. 发布文案 + 话题标签
7. 获客 CTA

## 硬口径（必须遵守）
- 缺失信息标注「待补充」，不臆造、不以估算值替代。
- 不使用绝对化 / 因果化表述（保证 / 100% / 最低价 / 因为…所以…）。
- 资费与政策以当期公示为准，需注明有效期。

## 执行
- 读取本目录 `references/` 下的模板与话术库。
- 产物写入 `outputs/<项目名>/`，按项目归档。

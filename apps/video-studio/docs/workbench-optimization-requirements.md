# 工作台优化设计需求

本文档基于当前 Video Studio 工作台现状，以及参考图中的「Silas AIGC 影视生产工作流」整理。目标是先明确产品与设计优化方向，不涉及代码修改方案。

## 1. 背景

当前工作台已经具备基础的视频生成链路：配置模型 API、输入剧本或素材、生成剧本、拆解分镜、生成关键帧组图、组合提示词、批量生成视频、保存历史记录。

但从影视生产视角看，当前形态更接近「AI 视频生成工具」，还没有形成完整的「影视生产流水线」。参考图强调的是从创意输入到 Seedance 抽卡、验收、局部修复、结尾帧衔接、声音后期和发布入库的一整套流程。

下一阶段优化重点不是简单增加按钮，而是把工作台升级为可控、可验收、可复盘的 AIGC 影视生产系统。

## 2. 总体目标

将当前工作台从三栏生成工具升级为 12 步影视生产管线：

```text
创意输入 -> 剧本诊断 -> 导演拆解 -> 美术圣经 -> 空间锁定 -> 分镜运镜 -> Seedance 提示词 -> 抽卡验收 -> 局部修复 -> 结尾帧锁定 -> 衔接剪辑声音 -> 后期发布入库
```

核心原则：

- 生成前有约束：人物、场景、空间、风格、禁用项都应结构化。
- 生成中有状态：每个镜头应有清晰的阶段、任务和进度。
- 生成后有验收：结果能按人物、动作、空间、运镜、衔接等维度检查。
- 失败后能定向修复：只修改失败维度，不整段推翻。
- 镜头之间能衔接：每段 15 秒视频的结尾帧可作为下一段继承依据。
- 项目能够沉淀：项目、素材、提示词、关键帧、视频、复盘记录都能入库。

## 3. 当前工作台现状

### 3.1 已有能力

- 三栏布局：左侧配置、中间创作、右侧历史记录。
- 支持文本、文件、图片作为剧本输入来源。
- 支持 AI 生成剧本和拆解分镜。
- 每个镜头已有字段：提示词、时长、景别、运镜、光线、色调、主体、场景、备注。
- 支持关键帧组图生成、上传、切割，以及单帧上传。
- 支持文本、关键帧、组图切割三种镜头生成方式。
- 支持复制单镜头模板、导出镜头 JSON、导出全部提示词。
- 支持批量生成视频、未完成生成、失败重试、任务队列。
- 支持项目保存、导入、导出、历史记录筛选。

### 3.2 主要缺口

- 缺少明确的生产流程导航，用户不知道当前处于哪一步。
- 剧本拆解前没有「可生成性诊断」。
- 分镜字段偏技术参数，缺少导演意图和叙事功能。
- 人物、场景、服装、道具、色彩、禁用项没有形成项目级美术圣经。
- 多人场景缺少空间关系锁定，容易出现站位漂移和方向混乱。
- 提示词仍以单镜头为中心，缺少首帧、时间线、结尾帧、衔接项的结构化表达。
- 生成结果没有验收流程，只有保存和查看。
- 失败后只能重试，缺少按失败维度局部修复的工作流。
- 关键帧已有基础，但「结尾帧继承下一镜头」没有产品化。
- 历史记录偏结果列表，不是完整项目库或资产库。
- 后期剪辑、声音、字幕、发布入库还没有独立阶段。

## 4. 信息架构优化

### 4.1 顶部项目状态栏

顶部应从简单品牌栏升级为项目状态栏，展示项目名称、当前生产阶段、镜头总数、已生成镜头数、待验收镜头数、已通过镜头数、失败镜头数、素材完整度和发布状态。

目标是让用户随时知道项目是否能继续进入下一阶段。

### 4.2 左侧项目资产与全局规则

当前左侧主要是 API 配置。生产阶段中，API 配置不是高频操作，建议弱化为设置入口。

左侧更适合承载：

- 人物库。
- 场景库。
- 道具库。
- 风格库。
- 色彩规则。
- 空间规则。
- 禁用项。
- Seedance 参数模板。
- 项目级生成规则。

### 4.3 中间主生产区

中间区域应随阶段切换，承载当前最重要的生产动作。

示例：

- 剧本诊断阶段：展示问题列表和修订建议。
- 导演拆解阶段：展示镜头目标、叙事功能、情绪转折。
- 分镜运镜阶段：展示镜头卡片、关键帧、运镜设置。
- 抽卡验收阶段：展示视频结果和验收表。
- 局部修复阶段：展示失败维度、修复提示词、版本对比。

### 4.4 右侧检查与版本面板

右侧不应只展示历史记录。建议根据当前阶段切换为辅助面板：

- 当前镜头质量检查。
- 当前镜头失败原因。
- 当前镜头版本记录。
- 上一镜头结尾帧和当前镜头首帧对比。
- 项目历史版本。
- 生成素材预览。

### 4.5 底部生产队列

当前已有任务队列雏形，建议升级为固定可见的生产队列，支持全部任务、正在生成、待验收、失败、已通过、已入库等筛选。

## 5. 12 步生产流程需求

### 5.1 创意输入

目标：把零散创意、剧情、图片、参考视频、音乐和风格样片整理为项目输入资产。

需求：

- 支持输入剧情梗概、完整剧本、参考视频、音乐、人物图、场景图、风格图。
- 支持选择项目类型：短片、广告、MV、剧情片、口播、分镜测试。
- 支持设置项目目标：总时长、单镜头时长、画幅、风格、生成模型。
- 支持将参考素材归入人物、场景、风格、声音等资产分类。
- 支持输入全局禁用项，例如不要文字、不要水印、不要变脸、不要多余肢体。

输出：项目基础信息、原始创意文本、参考素材资产、全局生成约束。

### 5.2 剧本诊断

目标：在拆分镜前判断剧本是否适合直接生成，提前发现容易翻车的内容。

需求：

- 自动检查剧情冲突是否清楚。
- 自动检查情绪转折是否明确。
- 自动识别抽象描述，例如“震撼、孤独、宿命感”等缺少可视动作的表达。
- 自动识别多人互动、复杂打斗、手部动作、拥抱、亲吻等高风险内容。
- 自动检查人物、地点、服装、道具是否前后一致。
- 自动指出哪些段落需要拆短镜头。
- 输出可生成性评分。

输出：剧本问题列表、风险等级、可生成性评分、修订建议、建议镜头数和镜头拆分策略。

### 5.3 导演拆解

目标：把剧本拆解为有导演意图的镜头，而不是只有提示词和参数。

每个镜头应补充：

- 镜头叙事功能：交代环境、推进动作、人物反应、悬念、转场。
- 本镜头要传达的信息。
- 本镜头的情绪变化。
- 观众第一眼关注点。
- 动作开始状态。
- 动作结束状态。
- 与上一镜头关系。
- 与下一镜头关系。
- 是否需要承接上一镜头结尾帧。

输出：导演拆解表、镜头顺序、每镜头叙事目标、每镜头动作起止点、镜头间衔接说明。

### 5.4 美术圣经

目标：建立项目级视觉规则，保证人物、服装、场景、道具和色彩在全片一致。

人物库字段：角色名称、年龄、身份、外貌特征、发型、服装、表情基准、可变化项、禁止变化项、参考图。

场景库字段：场景名称、地点类型、时代背景、空间结构、主要材质、光源方向、天气、时间、参考图。

道具库字段：道具名称、颜色、材质、尺寸、出现镜头、是否关键叙事道具。

风格规则字段：主色、辅助色、禁用色、画面质感、镜头语言倾向、光影风格。

输出：项目美术圣经、可注入每个镜头的全局视觉规则、项目级负面提示词。

### 5.5 空间锁定

目标：在多人、多物、多场景中固定空间关系，降低站位、朝向、视线和光线漂移。

需求：

- 定义左、中、右站位。
- 定义前景、中景、后景。
- 定义角色面向方向。
- 定义角色视线方向。
- 定义摄影机位置。
- 定义光线来源。
- 定义入口、出口、关键道具位置。
- 定义谁看谁、谁背对谁。
- 定义镜头轴线是否保持。

第一阶段可使用轻量空间卡片，不必做复杂平面图。

建议字段：左侧角色、中间角色、右侧角色、前景元素、背景元素、摄影机位置、光源方向、视线关系、禁止变化。

输出：场景空间锁定规则、镜头空间约束、自动注入提示词的空间描述。

### 5.6 分镜运镜

目标：把导演拆解、美术圣经和空间锁定落到每个镜头的可执行生成方案。

当前分镜卡片建议重构为标签页：

- 剧情：镜头目的、动作、情绪、对白、旁白。
- 画面：主体、场景、构图、景别、光线、色调。
- 运动：角色动作、镜头运动、开始帧、结束帧。
- 关键帧：首帧、中间帧、结尾帧、上传、生成、替换。
- 提示词：Seedance 提示词、禁用项、复制、导出。
- 验收：通过、失败、失败维度、修复建议。

输出：结构化分镜卡片、每镜头完整生成参数、每镜头关键帧计划。

### 5.7 Seedance 提示词

目标：生成更适配 Seedance 2.0 的结构化提示词，支持 15 秒分段和镜头衔接。

提示词应分层组织：

- 固定锁定项：人物、服装、场景、光线、色彩、画幅。
- 首帧描述：镜头开始看到什么。
- 时间线动作：0s、3s、6s、10s、15s 分别发生什么。
- 运镜描述：推、拉、摇、移、跟、环绕、固定。
- 禁止项：变脸、漂移、手部畸形、文字、水印、画面跳变。
- 衔接项：继承上一镜头结尾帧，保持方向和动作连续。
- 声音提示：环境声、拟音、台词、音乐情绪。

输出：基础版提示词、严格锁定版提示词、修复版提示词、单镜头导出包、全片提示词导出包。

### 5.8 抽卡验收

目标：让每个生成结果都经过标准化检查，避免只靠主观回看判断。

每个视频生成后进入「待验收」状态。验收维度包括：

- 人物一致性。
- 服装一致性。
- 位置和空间关系。
- 动作连续性。
- 运镜是否符合。
- 表情是否正确。
- 光线和色调是否一致。
- 是否有畸形、变脸、水印、文字。
- 结尾帧是否可接下一镜头。

验收动作：通过；小问题进入局部修复；大问题重抽本镜头；结构问题退回分镜运镜或空间锁定。

输出：验收结果、失败维度、返修建议、镜头状态更新。

### 5.9 局部修复

目标：遵循「只改失败维度，不要整段推翻」的规则，降低返工成本。

支持选择失败类型：

- 人脸不像。
- 手部错误。
- 人物位置错误。
- 空间关系错误。
- 光影错误。
- 运镜错误。
- 动作不顺。
- 结尾帧不可衔接。

系统应根据失败类型生成定向修复提示词：

- 如果人物位置错，只补充空间锁定和站位约束。
- 如果脸不像，只强化人物外貌和参考图，不重写剧情。
- 如果运镜错，只修改镜头运动描述，不改变动作和场景。

输出：修复提示词、修复任务、修复版本、原版与修复版对比。

### 5.10 结尾帧锁定

目标：保证每段视频的最后一帧能作为下一段的首帧参考，实现 15 秒分段衔接。

需求：

- 每个镜头支持提取、上传或指定结尾帧。
- 结尾帧可标记为下一镜头首帧参考。
- 显示上一镜头结尾帧和当前镜头首帧并排对比。
- 检查人物方向、景别、光线、动作是否连续。
- 支持手动指定继承规则：人物、服装、场景、姿势、光线、视线方向。

输出：镜头结尾帧、下一镜头继承规则、衔接风险提示。

### 5.11 衔接剪辑声音

目标：从单段视频生成进入全片剪辑和声音设计。

需求：

- 支持镜头排序。
- 支持每段视频预览。
- 支持转场备注。
- 支持台词和字幕文本。
- 支持环境声、拟音、音乐、低频提示。
- 支持标记剪辑点。
- 支持记录声音后期要求。

输出：剪辑顺序、字幕文本、声音设计表、后期处理清单。

### 5.12 后期发布入库

目标：把最终项目、素材、提示词、关键帧、视频和复盘记录沉淀为可复用资产。

需求：

- 支持项目入库。
- 支持项目状态：草稿、生成中、待验收、返修中、已完成、已发布。
- 支持导出发布包。
- 支持调色、字幕、水印、署名、导出规格备注。
- 支持复盘记录：成功提示词、失败原因、修复策略。
- 支持按项目、角色、场景、风格、模型、状态筛选。

输出：项目库记录、发布包、复盘记录、可复用素材资产。

## 6. 镜头状态设计

建议为每个镜头建立明确状态：

```text
未拆解 -> 已拆解 -> 待补全规则 -> 待生成 -> 生成中 -> 待验收 -> 已通过 -> 需修复 -> 修复中 -> 已锁定结尾帧 -> 已入库
```

状态与动作：

| 状态 | 主要动作 |
| --- | --- |
| 未拆解 | 拆分镜 |
| 已拆解 | 补充导演意图、美术、空间 |
| 待补全规则 | 补充人物、场景、空间、禁用项 |
| 待生成 | 生成关键帧、生成视频 |
| 生成中 | 查看任务、取消任务 |
| 待验收 | 播放、打标、通过、返修 |
| 已通过 | 锁定结尾帧、进入后期 |
| 需修复 | 选择失败维度、生成修复提示词 |
| 修复中 | 查看修复任务 |
| 已锁定结尾帧 | 衔接下一镜头 |
| 已入库 | 导出、复盘、复用 |

## 8. 优先级建议

### P0：流程骨架和镜头状态

优先增加 12 步流程导航、镜头状态、验收状态、失败维度。

价值：立即把工作台从「生成器」升级为「生产台」。

### P1：剧本诊断、美术圣经、空间锁定

建立生成前约束体系，减少无效抽卡。

价值：提升首轮生成成功率和一致性。

### P2：分镜卡片重构和提示词模板

把每个镜头从单一 prompt 升级为结构化镜头包。

价值：提升提示词稳定性和可维护性。

### P3：抽卡验收、局部修复、结尾帧锁定

建立生成后的质量闭环。

价值：降低返工成本，支持 15 秒分段衔接。

### P4：后期发布入库

把项目、素材、提示词和复盘沉淀为资产。

价值：支持复用、团队协作和长期生产。

## 9. 首期 MVP 建议

如果需要先做一个最小可用版本，建议聚焦以下内容：

1. 增加顶部 12 步流程导航。
2. 给镜头增加状态：待生成、生成中、待验收、已通过、需修复。
3. 增加验收面板，支持按失败维度打标。
4. 增加局部修复提示词生成，不改变原镜头其他成功字段。
5. 增加结尾帧锁定字段，并在下一镜头提示词中引用。
6. 增加项目级美术圣经的最小版本：人物、场景、禁用项。

该 MVP 不需要一次性完成剪辑、声音和完整资产库，但应先把「生成 -> 验收 -> 修复 -> 衔接」的闭环做出来。

## 10. 验收标准

优化后的工作台应满足：

- 用户能清楚知道项目当前处于 12 步流程的哪一步。
- 每个镜头都有独立状态和下一步动作。
- 剧本拆解前能看到可生成性风险。
- 人物、场景、道具、色彩、禁用项能作为项目级规则复用。
- 多人场景能明确站位、视线、光源和摄影机位置。
- 每个镜头提示词包含首帧、时间线、运镜、禁用项和衔接要求。
- 每个生成结果必须经过验收才能进入下一阶段。
- 失败结果能按具体维度修复，而不是只能重抽整段。
- 每个通过的镜头能锁定结尾帧，并作为下一镜头衔接参考。
- 项目能保存完整生产资料，包括剧本、分镜、素材、提示词、视频、验收和复盘记录。

## 11. 总结

当前工作台已经具备 AI 视频生成的基础能力，但要匹配参考图中的 AIGC 影视生产工作流，需要从「生成工具」升级为「生产流程管理系统」。

下一阶段优化重点应放在：流程分阶段、规则结构化、镜头可验收、失败可定向修复、结尾帧可衔接、项目可入库复盘。

这样才能支撑 Seedance 2.0 类 15 秒分段生成工作流，并减少反复抽卡和整段返工。
